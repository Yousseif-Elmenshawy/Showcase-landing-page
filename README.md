# صفحة أعمال مشابهة

صفحة Front-End بسيطة لعرض صور نماذج أعمال مشابهة لصفحات Landing Pages.

## التشغيل
افتح `index.html` في المتصفح.

## إضافة صورك
افتح `app.js` وعدّل مصفوفة `projects` في أعلى الملف:

```js
const projects = [
  {
    image: "ضع رابط الصورة هنا",
    title: "اسم المشروع",
    description: "وصف مختصر"
  }
];
```

أضف عنصراً جديداً لكل صورة. يمكنك استخدام رابط صورة مباشر، أو وضع الصور داخل مجلد بالمشروع واستخدام مسار مثل:
`images/project-1.jpg`

لا يحتاج المشروع إلى Backend أو قاعدة بيانات أو أي مكتبات JavaScript خارجية.
